# Changelog

## 0.1.0 — 2026-11-14

- Add Linux monitoring for revision A 3.5-inch USB displays.
- Display CPU, NVIDIA GPU, RAM, root filesystem usage and uptime with visual levels.
- Include optional RAPL CPU power and NVIDIA GPU power readings.
- Send incremental RGB565 rectangles and recover from USB failures and suspend.
- Provide PNG previews, deterministic demo data and repository-local profiling tools.
- Include explicit optional systemd installation, removal and rollback support.
